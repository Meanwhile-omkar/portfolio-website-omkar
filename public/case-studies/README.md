# Case Study Images

Each case study has its own folder:

## Folders:
- `spotify/` - Spotify India case study slides and photos
- `ies-retail/` - IES retail analytics case slides
- `iim-ahmedabad/` - IIM Ahmedabad workplace inclusion case
- `iit-bombay/` - IIT Bombay post-merger case

## What to add:
- Presentation slides (2-3 key slides as images)
- Photos of you presenting
- Team photos
- Award/certificate photos

**Naming tips:**
- `slide-1.jpg`, `slide-2.jpg` for presentation slides
- `presenting.jpg` for presentation photos
- `team.jpg` for team photos
- `award.jpg` for awards

The system will auto-detect all images in each folder!
